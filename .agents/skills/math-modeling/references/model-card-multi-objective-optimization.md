# 带约束多目标优化模型卡

## 模型名称与路由信号

带约束多目标优化用于两个或三个互相冲突目标下的连续决策，例如同时降低成本、风险和服务损失。输出是经过可行性复算的 Pareto 近似集，而不是一个天然最优答案。它不能仅凭 NSGA-II 返回值证明全局 Pareto 最优，也不能替代目标定义、偏好来源或约束口径审查。

## 适用结构

- 有 2 至 3 个可数值求值且方向明确的目标；
- 决策变量连续，每个变量都有有限边界、单位和来源；
- 约束可写成小于等于、大于等于或等于，并能独立重新代入；
- 决策者需要看到目标冲突、可行方案范围及偏好变化的影响；
- 每次目标求值成本适合固定种群、代数和多种子预算。

当前基线不处理整数、二元、类别或混合变量，也不把四个以上目标投影成看似完整的二维前沿。

## 符号与单位

- x：连续决策向量，各分量保留原单位和有限上下界；
- f_j(x)：第 j 个原始目标，保留最小化或最大化方向及业务单位；
- F_j(x)：内部统一最小化目标，最大化目标使用 F_j=-f_j；
- g_i(x)、h_k(x)：不等式和等式约束；
- z*、z_nad：由已验证参考前沿得到的理想点和最差端点；
- f_norm=(F-z*)/(z_nad-z*)：无量纲归一化目标；
- w_j：正数且和为 1 的偏好权重，不是数据自动发现的客观真值。

## 假设与定义风险

目标、约束、变量边界和参数口径必须与题意一致，表达式在搜索域内可求值。目标方向、损失聚合、容量和服务约束的时间窗口、权重来源、参考前沿范围均可能实质改变结论，必须进入模型定义寄存器。数值收敛不能解决漏约束、量纲错误或目标定义错误。

参考前沿是验证契约，不是装饰线。受控二维例使用确定性密网格并明确分辨率；实际问题优先使用解析前沿、穷举或高精度专用求解器结果、哈希绑定的外部参考。没有可信参考时只能报告多种子内部一致性，不能宣称已验证前沿质量。

## 透明基线

先分别优化或枚举每个单目标端点，并给出至少一个人工可行方案；低维问题使用粗网格直接展示目标冲突和约束边界。这些结果检查目标方向、尺度和极端解是否合理。NSGA-II 只有在同一目标与约束下比透明基线覆盖更多有效折衷且稳定性门通过时，才作为主前沿生成器。

## 模型构造

生产基线使用受限算术表达式定义变量、目标和约束，仅允许有限常数、基本运算及白名单单参数函数。pymoo NSGA-II 采用可行性优先的约束处理，按多个预声明种子分别搜索。每个返回点随后使用原表达式独立复算目标、边界和约束，去重后重新执行非支配检查，再合并成前沿。

稳定性在由参考理想点和最差端点定义的无量纲空间中衡量：每个种子的 IGD、固定参考点超体积比、超体积比跨种子极差和端点缺口都必须满足输入中预声明的门槛。门槛失败时仍保留完整证据，但 CLI 返回非零状态。

折衷解使用归一化加权 Chebyshev：max_j(w_j f_norm,j) + 0.001 sum_j(w_j f_norm,j)。第二项只用于并列打破。该解始终表述为“给定归一化与权重下的偏好条件解”，不能称作综合最优。

## 输入和参数

输入 JSON 必须包含：

- variables：名称、连续类型、有限上下界、单位和来源；
- objectives：2 或 3 个唯一名称、方向、表达式、单位和来源；
- constraints：至少一项名称、方向、表达式、右端值、单位和来源；
- solver：NSGA-II、种群规模、代数、至少两个不重复固定种子、可行/去重容差和预声明稳定性门槛；
- decision：主权重、至少一组敏感性权重及区域变化门槛；
- reference_front：二维受控问题的密网格分辨率与来源，或外部 CSV 路径、SHA-256 和来源。

种群、代数、门槛、权重和参考分辨率都要在运行前确定并记录。不得看到结果后只放宽失败门槛；若预算调整，保存旧证据并解释原因。

## 验证设计

- must：用原表达式复算每个输出点的变量边界、全部约束和原始单位目标；
- must：对每个种子和合并前沿重新检查非支配性；
- must：固定种子、种群和代数，保存各种子前沿及运行版本；
- must：绑定并验证独立参考前沿，拒绝零目标范围和失配 SHA-256；
- must：在同一无量纲空间计算每种子 IGD、超体积比、跨种子差异和端点覆盖；
- must：稳定性失败时保留失败证据并阻断成功状态；
- should：比较单目标端点、人工可行方案或低维网格基线；
- should：增加种群或代数，检查结论区域而非单个小数是否稳定；
- optional：用另一算法、解析关系或专用求解器交叉验证关键前沿段。

## 敏感性与稳健性

至少扰动主权重，覆盖偏重各目标和均衡权重，并报告选择点在归一化目标空间的移动距离。对会改变可行域的容量、最低服务、风险上限或边界做情景扰动；对高计算成本问题比较搜索预算和种子数。归一化范围变化会改变折衷点，必须连同权重一起敏感性分析。

## 失败模式

- 把 NSGA-II 返回点直接称为全局 Pareto 最优；
- 只检查求解器可行标志，不用原约束重新代入；
- 不记录单位，导致大量纲目标在权重选择中隐性占优；
- 用本次合并前沿同时充当真值和验证参考，形成循环验证；
- 目标零范围仍继续归一化，产生任意折衷；
- 单种子、单预算或只看一张平滑图就宣称稳定；
- 先看结果再挑权重或稳定性门槛；
- 把偏好权重写成“客观权重”或把折衷解写成唯一最佳方案；
- 对离散决策使用连续结果后随意四舍五入，破坏约束。

## 替代模型与选择证据

若目标可以按已审查的固定价格或效用换算为一个目标，先用线性、整数或连续非线性单目标模型，并报告换算敏感性。若决策变量离散，使用 MILP、混合变量进化算法或可验证枚举。两个目标且一个可转为明确阈值时，可比较 epsilon-constraint 方法；它更容易解释约束阈值与单目标最优性。四个以上目标应评估 NSGA-III 或 MOEA-D 和高维可视化，不能沿用当前二维证据门。

选择 NSGA-II 的证据应是目标确实冲突、需要保存多个可行折衷、参考验证和多种子稳定性均可实施。

## 输出证据

multi_objective_optimization.py 生成 pareto_solutions.csv、constraint_check.csv、seed_stability.csv、compromise_sensitivity.csv、seed_fronts.csv、reference_front.csv、二维 pareto_front.png 和 run.json。机器证据包含输入 SHA-256、Python/NumPy/pymoo 版本、全部变量/目标/约束定义、搜索预算、参考前沿绑定、归一化范围、逐种子指标、稳定性门、合并前沿复算、折衷公式、权重敏感性和主张限制。
