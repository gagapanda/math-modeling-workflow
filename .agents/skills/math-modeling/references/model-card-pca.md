# 主成分分析（PCA）模型卡

## 模型名称与路由信号

主成分分析用于把一组相关数值特征转换为少量互相正交的线性方向，以诊断共线结构、压缩维度、构造后续模型输入或辅助可视化。它不发现样本类别，不证明因果，也不自动给出带偏好含义的综合评价排名。

## 适用结构

- 每行是一个明确样本，每列是完整的数值特征；
- 目标是保留主要线性方差结构，而不是直接预测标签或求最优决策；
- 特征间存在相关性或下游模型面临共线性、高维输入问题；
- 线性组合具有可接受的业务解释，且可报告被舍弃的信息；
- 样本与特征的定义、单位和采集口径一致。

## 符号与单位

- x_ij：样本 i 的第 j 个原始特征，保留原字段单位；
- z_ij：按训练样本均值和标准差做 z-score 后的无量纲值；
- v_k：第 k 个主成分的单位特征向量；
- t_ik = z_i v_k：样本 i 在第 k 个主成分上的无量纲得分；
- lambda_k：第 k 个主成分的样本方差；
- r_k = lambda_k / sum(lambda)：解释方差比例；
- m：按累计解释方差阈值和可选成分上限实际保留的维数。

## 假设与定义风险

PCA 依赖线性结构和方差尺度。特征选择、样本边界、标准化方式、异常值处理、训练窗口和保留阈值都可能改变主成分，必须在模型定义寄存器中登记。标准化 PCA 让每个非恒定特征具有相同方差，但不代表业务重要性相同。

样本数不大于特征数时仍可通过 SVD 分解，但秩受限且载荷解释脆弱；这不是自动拒绝条件。KMO 和 Bartlett 检验可服务特定因子分析论证，但不是运行 PCA 的通用必需门禁。

## 透明基线

零成分基线用每个特征的训练均值重构所有样本。生产输出比较保留成分的标准化重构误差与该均值基线，并同时给出相关矩阵、原尺度方差占比和标准化后的等方差占比。若保留全部可用成分，则重构接近精确，但没有实现降维。

## 模型构造

先对声明的完整数值特征显式 z-score，再使用 deterministic full SVD 拟合全部可用主成分。按累计解释方差达到 `variance_threshold` 的最小维数选择成分；可选 `max_components` 只作为明确上限，若导致阈值未达到，输出必须记录失败警告。

为保证重复运行字节稳定，每个特征向量把最大绝对系数对应的符号规范为正。该规则不改变子空间，也不赋予方向业务含义。相关载荷、特征向量系数、平方系数份额和样本得分分别输出，不混为同一个“权重”。

## 输入和参数

必须提供 CSV、至少两个显式特征列；建议提供完整且唯一的 ID 列。特征必须是有限、无缺失、非常数的数值。必须声明累计解释方差阈值；需要硬性压缩时再声明最大成分数。当前脚本最多接受 500 个特征，不静默插补、不编码类别变量，也不把结果自动转换为排名。

## 验证设计

- **must**：检查缺失、非数值、非有限值、常数特征、重复 ID 和特征列歧义；
- **must**：记录输入 SHA-256、训练均值、尺度、完整解释方差谱、保留规则和符号规则；
- **must**：报告累计解释方差是否达到阈值，不能把成分上限造成的不足静默处理；
- **must**：用原数据复算整体、逐样本和逐特征重构误差，并与均值重构基线比较；
- **must**：输出特征向量系数、相关载荷和平方系数份额，解释时明确三者区别；
- **should**：比较标准化与原尺度方差份额、不同阈值和异常值处理；
- **should**：若用于下游预测或聚类，只在训练分区拟合 PCA，并在下游任务自己的验证框架中比较有无 PCA；
- **optional**：用 bootstrap、时间切片或分组切片比较子空间和载荷稳定性。

## 敏感性与稳健性

至少扰动累计解释方差阈值和异常值处理；量纲差异明显时比较标准化与不标准化的研究问题，并解释为何选择其中之一。若主成分用于下游模型，应比较原始特征、PCA 特征及不同保留维数的留出表现。载荷接近或样本少于特征时，应检查重采样后的子空间稳定性，而不是依赖单次符号和排序。

## 失败模式

- 把 ID、标签、时间泄漏字段或决策结果作为 PCA 特征；
- 用全数据拟合 PCA 后再做预测切分，造成预处理泄漏；
- 未记录标准化，导致大量纲特征支配方差；
- 仅凭累计解释方差高就宣称保留了业务信息；
- 把特征向量系数、相关载荷或主成分得分直接称作指标权重；
- 用方差贡献率加权得分自动生成评价排名，却没有偏好方向、权重依据和排名稳定性验证；
- 把二维投影中的视觉分离当作聚类或真实类别证据；
- 把主成分符号、成分顺序的小扰动解释成实质变化。

## 替代模型与选择证据

若目标是有偏好的方案排序，应使用具有明确正负向和权重语义的 TOPSIS、AHP 等评价模型；若目标是样本分组，应使用聚类并验证稳定性；若目标是预测，应比较正则化回归或其他监督模型的留出表现。非线性流形可比较 Kernel PCA、UMAP 或自编码器，但必须增加调参与外推风险证据。因子分析适合潜变量测量假设，与最大化样本方差的 PCA 不等价。

## 输出证据

脚本输出样本得分及逐样本误差、完整解释方差谱、特征向量与相关载荷、预处理参数及尺度风险、相关矩阵、原尺度重构、逐特征误差，以及绑定输入哈希、阈值状态、均值基线和限制警告的 `run.json`。这些输出描述拟合样本的线性方差结构，不是默认评价等级。

## 下一步动作

运行 `scripts/model_baselines/pca.py` 前先确认降维目的、样本边界和特征口径。先查看相关矩阵与原尺度方差份额，再执行标准化 PCA；若结果进入预测或聚类，必须把拟合放进对应训练/验证流程。项目现有 sklearn 依赖已足够，无需额外安装。
