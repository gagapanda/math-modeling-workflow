# 跨题型论文表达快速调用卡（比赛入口）

> 状态：基于 2023 A127、2024 A016、2025 C132、2025 E030 代表性论文表达卡，以及机理/几何、优化、统计预测、概率分类/评分与聚类/分组、评价/综合评分五类隔离增强验证形成；并已收敛后续公式、结果表、证据载体、段落逻辑、正文/附录和参考文献专项验证。本卡是比赛写作的最小执行接口，不是固定页数、公式数或图表数模板；未验证的题型规则不得由此卡自动推出。

## 1. 使用方式

每个实质性小问先写一条“直接回答”，并将它放在该小问标题后的第一个实质性段落中，再用证据把它支撑起来；不要先写数据清洗、方法背景或代码流程后才公布答案。正文按“评委需要先知道什么”组织，不按代码执行顺序堆叠。评委首读至少应能依次找到：

在真实填充的正文中，每个实质性小问至少形成一个可独立阅读的局部闭环：

```text
直接回答
→ 核心公式/算法及其计算职责
→ 结果载体与证据分工
→ 匹配验证/失败结构
→ 适用边界
→ 最终回答回扣
```

这是一种段落组织方式，不要求强制增加小标题、公式、图表或页数；公式、表、图和结果文件不互相替代。

```text
本问答案
→ 为什么采用该定义/模型
→ 哪个公式、表或图直接支撑
→ 如何验证
→ 结论在什么条件下成立
```

每完成一问，至少形成一条可追溯链：

```text
题目转化
→ 定义、符号与单位
→ 关键假设/定义边界
→ 核心公式或机制推导
→ 透明基线
→ 主模型/有理由的改进
→ 算法与求解状态
→ 关键结果
→ 比较、诊断或敏感性证据
→ 验证与适用边界
→ 直接回答
```

题型不适用的环节可以裁剪，但要在工作记录中写明“为何不适用”，不能用方法名称替代缺失的定义、推导或验证。

需要细化时按需下钻，不在本卡复制全部规则：

- 写作前安排逐问主张和证据：见 [paper-evidence-storyboard.md](paper-evidence-storyboard.md)；
- 构建、公式导出、分页与视觉检查：见 [paper-production.md](paper-production.md)；
- 公式、图表、创新、叙事和附录的详细规则：见 [paper-claim-figure-innovation-card.md](paper-claim-figure-innovation-card.md)；
- 匿名、AI、最终包和提交检查：见 [submission-checklist.md](submission-checklist.md)。

### 1.1 本次验证后新增的高价值提醒

- **统计通路不可混写**：同编号配对、对象层汇总、时间序列窗口、重复测量和交叉验证折组分别登记分析单位与有效分母；不要把“配对后汇总”写成所有分析都遵循的单一路径。
- **选择理由必须可重建**：正文要能回答“为什么用这个基线、特征、权重、验证单位和情景比例”，但没有时间戳证据时不要使用“预先声明/预注册”来增强可信度。
- **连续情景要回到测量语义**：若输入来自离散帧、试次或等级，连续插值只表示模型情景，不是一次观测可以精确实现的事实。
- **内部话术要出正文**：删去模板、流程、修复、工作区和作者操作叙述；保留对数据缺失、外推、未执行实验和结论限制的科学说明。

## 2. 强制门、建议项与时间不足时的降级

### 2.1 强制门（MUST）

- **直接回答**：每个正式小问都要有明确的答案、方案、区间或判断，带单位/取值域和适用条件。
- **符号入口**：完整论文在实质性模型前设置独立“符号说明/符号与单位”；局部新符号在首次使用处定义。符号表至少有符号、含义、单位/域，必要时有索引范围和信息时点。
- **定义与量纲**：写清预测对象/决策对象、数据层级、关键定义和量纲闭合；有歧义时登记采用定义及其影响。
- **分析集与分母**：有筛选、匹配、缺失、重复测量或训练/验证划分时，写清“候选范围→分析单位→有效分母→未进入原因→验证单位”；文件数、行数、试次数、独立对象数、配对数和验证组数不得互换或跨问相加。
- **数据证据到建模动作**：数据审计只回答数据能否使用；仅当观察到的分布、趋势、周期、群组差异或异常结构会改变模型路由、变量变换、验证结构或决策解释时，才在正文给出最小“分析单位→可见模式→下游动作→禁止推出的更强结论”交接。无下游作用的探索图表删除或下沉，不用全量直方图、相关热图或描述统计填充篇幅；不把观察相关写成因果，也不把样本内模式写成域外保证；机理、几何、纯优化或无数据题可明确不适用，不强制 EDA。
- **核心推导**：保留从现实关系到可计算公式/约束/损失函数的最短连续推导；公式必须解释变量、计算职责、输出去向和与结果的连接。
- **推导正文停点**：关键推导不得省略会改变分母、权重、方向、单位、索引/数据层级、损失/约束、变量域、模型选择、结果或决策的材料性步骤；达到“可计算式→冻结结果/选择→复核入口”后停止扩写，教材证明、机械代数和库内部步骤下沉，不因‘充实’继续加公式。
- **材料性公式见证**：会改变直接答案、模型选择、排序、阈值、可行性或情景动作的核心公式，在进入结果前至少给一个类型匹配且不只是同路径回算的验证见证；写清检查对象、期望关系、实际结果、允许范围和失败动作。
- **基线与选择理由**：至少一个透明、可复算基线；说明基线缺陷、主模型新增结构及同口径比较方式。
- **比较—最终拟合身份**：候选比较只使用预先登记的分析/部署单位、折分或时间窗、折内预处理、指标聚合、候选集、选择规则和搜索预算；比较性能与选择后全量重训的参数/目标输出分开登记。最终拟合输出不得重新包装为无偏验证性能；改变任一比较或最终拟合口径时解除冻结并重算。
- **结果可追溯与身份回指**：正文数字来自冻结结果登记或明确计算；同一冻结结果应在结果登记、正文主张、结果表/图注和附录/支撑材料入口保持同一身份（比较结果、模型选择、最终拟合等不同角色分别标记）；表、图、正文和附录数字、单位、精度与主张口径一致。冻结结果、表图或支撑材料变化时，重新对账全部入口；身份标签只用于导航，不证明模型正确、验证充分或外部有效。
- **图形编码真实性**：图形本体区分观测、汇总统计、模型输出和条件情景；只有有限登记节点时，不用连续实线暗示未计算的完整响应函数；材料性类别、阈值、基线和选择点不能只靠颜色区分。
- **图内语言与面板身份**：中文论文的材料性图形原则上采用与正文一致的主语言；单位、变量、专名及 `MAE/RMSE` 等通用缩写可保留但须与正文一一对应。承担不同主张或需单独引用的面板使用稳定 `(a)(b)…` 或独立图号，正文和图注不用左/右/上/下位置词唯一定位；来源未解释的图内字符不得擅自赋义。
- **验证与边界**：验证方式必须匹配主张；同时写出限制、外推范围和不可推出的更强结论。
- **诊断到模型处置**：凡正文保留的材料性诊断或检验，写清检查对象与期望关系/阈值、实际证据和模型处置（限域接受、限制保留、修订或拒绝）。若修订模型、数据处理或验证结构，必须重跑受影响验证并重新冻结依赖的数字、表图和结论；无下游处置的诊断图、残差图或检验罗列删除或下沉。单项检验通过不证明模型正确、唯一最优、外部有效或部署安全；单项失败也不自动否定与其无关的全部主张。
- **成品检查**：公式、表号、图号、单位、正文引用和最终 DOCX/PDF 必须检查；结果冻结后再进入摘要、正式结论和最终提交物。

### 2.2 建议项（SHOULD）

- 用一张有明确主张的图或表展示数据结构、模型必要性、候选比较、参数影响、可行性、误差/不确定性或失败边界。
- 报告逐组/逐时段失败结构，而不是只报总体均值。
- 对关键假设做敏感性、稳健性、收敛或定义替代比较。
- 把“现实意义”写成可观察的决策含义，把创新写成“现实缺口→模型改进→验证收益/解释增量”。
- 对机理/动态题保留最短连续闭环：现实对象与外部驱动 → 状态变量 → 状态方程 → 初始/边界条件 → 参数来源或标定目标 → 数值推进/事件提取 → 指标与决策；机制图只在能标明输入、状态、边界/事件和输出且可与方程逐项对应时使用。
- 把完整代码、全量结果、哈希和内部审计证据放入附录或支撑材料，正文保留足以独立理解的核心内容。

### 2.3 时间不足时的降级顺序（DROP）

按以下顺序砍掉工作，不得反过来：

1. 新模型、新外部数据和非必要敏感性；
2. 装饰性图、重复结果表和长篇背景；
3. 非关键中间推导的展开，但保留核心方程、变量定义和选择理由；
4. 版式润色。

不能砍掉：直接回答、符号/单位、核心公式、透明基线、结果对账、匹配验证、限制边界、匿名/AI/提交检查。

## 3. 一页逐问填写模板

```text
Q__｜直接回答：________________（单位/条件：____________）
题目转化：输入______；要决定/预测/解释______；输出______。
符号与单位：新增符号______；单位/域______；信息时点/索引______。
定义与假设：采用定义______；材料性假设______；类型（材料性假设/操作性定义/验证设计/情景条件）______；作用/受影响主张______；可检查信号（直接/间接/当前不可检验）______；违反后降级______；放宽路径/重算______；不能推出______。
分析集与分母（有材料性变化时）：候选______；筛选/配对/分组______；分析单位______；有效分母______；未进入原因______；验证单位______。
核心公式/逻辑：
  (1) ______；其中______；由______得到______。
  (2) ______；它把______连接到______。
公式见证：检查对象______；类型（独立/半独立/同路径自洽）______；期望关系______；实际结果/容差______；失败动作（拒绝/降级/重算）______。
透明基线：______；基线不足是______。
主模型/改进：增加______，因为它解决______；不增加______的理由是______。
算法与状态：输入______；步骤______；停止/收敛/求解状态______。
关键证据：表/图______支持主张“______”；来源/单位/范围______。
结果身份与回指（有材料性结果时）：冻结结果登记______；正文主张 ID______；结果表/图 ID______；附录/支撑入口______；四者是否同一版本______；变化后是否重新对账______。
性能—方案双载体（题目同时要求二者时）：性能/效果______；方案/参数/动作______；二者共同条件及关系______。性能数字必须能由当前方案变量、目标函数或明确的情景合同回指；不能回指时分开报告，不制造效果—方案连接。
验证：方法______对应主张______；结果______；失败/异质性______。
敏感性/稳健性（材料性时）：扰动对象______；范围/替代口径______；响应指标______；稳定性判据______；失败边界/重算触发______；证据状态（已量化/已识别未量化/未建立）______。
数值设置与来源合同（材料性时）：设置______；角色（观测输入/折内估计量/拟合参数/固定阈值/固定超参数/报告水平/情景旋钮）______；来源/估计方式______；选择/标定口径______；已完成验证______；未证明边界______；改变后重算______。
适用边界：______；外推/因果/最优性限制______。
最终回答回扣：因此对 Q__ 的回答是______。
```

### 3.1 多问依赖与重算接口（仅在材料性依赖存在时）

跨问综合不是第二份逐问结果摘要。若前问的定义、数据、模型或不确定性会改变后问的主张、验证或决策，至少记录：

```text
上游资产/定义
→ 实际传递量与风险类型
→ 受影响的下游主张
→ 控制/验证
→ 失效范围与重算触发
```

优先检查四类传播：定义/测量、样本结构/因果边界、预测不确定性、决策触发。上游点估计不能无条件传成下游确定输入；观察性关联不能因进入预测或优化模型而升级为因果机制；下游检验不能修复上游定义错误。若传播幅度无法量化，至少说明受影响对象、失效方向和回退动作。无材料性依赖时简短说明即可；只有节点、传递量、风险和动作都可读时才画依赖图，不强制新增表或图。
### 3.2 贡献主张的全文落位（只对材料性贡献使用）

准备把结构写成“贡献、改进或创新”时，先建立：

```text
贡献类型 + 现实缺口 + 新增结构
→ 正文首次证明位置
→ 匹配证据/基线/消融
→ 收益、失败与边界
→ 结论回收
```

技术路线只预告，正文负责首次证明，验证负责收益与失败，结论只回收。定义、数据组织、验证、决策和证据链可以是贡献，但不是算法创新。没有逐组件消融时，不把整体性能收益归因于某个特征、权重、预处理或组合模块；没有材料性增量时不强制制造创新点。普通教材方法、多软件、图表数量、模型组合和一般调参不自动构成贡献。
## 4. 五类已验证题型适配器

### 4.1 机理/几何/动态题

```text
现实对象与外部驱动
→ 若题目要求事件/峰值/阈值/状态提取，先将题面事件对应到操作性判据，并说明输出进入哪个指标及不等同于哪种更强现实量
→ 坐标/时间映射与状态变量
→ 状态方程及关键项职责
→ 初始条件/边界条件
→ 参数来源或标定目标
→ 数值推进与阈值/峰值/积分事件
→ 指标与决策
→ 收敛/参数/结构/定义敏感性与边界
```

正文重点回答：现实输入如何变成空间/时间驱动和状态量；若题目要求事件、峰值、阈值或状态提取，先说明题面要求对应的操作性判据、判据输出进入哪个指标，以及它不等同于哪种更强的现实量；状态方程、初边值与参数如何闭合；数值推进后如何提取阈值、峰值、积分或约束事件；结果如何由机制产生。只保留支撑本题计算的最短连续推导，不为增加公式数量复制教科书推导。等效标定参数不得包装成已由独立试验识别的物性或因果机制。机制图必须标明输入、状态、边界/事件和输出并与方程逐项对应，不能只画通用流程。

### 4.2 约束优化/多目标/鲁棒决策题

```text
决策变量与取值域
→ 目标函数与约束
→ 可行基线
→ 搜索层级与优化器真实状态
→ 最终精度可行性复算
→ 活跃约束
→ 候选比较/选择偏好
→ 多目标权衡
→ 鲁棒代价
→ 最优性边界
```

先证明候选可行，再谈目标值。结果段不能停在“参数表 + 目标值”：至少解释哪些约束或变量边界塑造当前候选、目标增益来自何种方案结构、哪个资源/对象/时段是瓶颈、多目标或总和目标隐含何种决策偏好，以及何种定义、约束或偏好变化必须触发重新优化。`success=false`、迭代上限、局部停止或异常退出必须如实保留；有限搜索只能写“在声明搜索空间内找到的最佳候选”，不能无证据写成全局最优。替代定义若有实质影响，应重新优化而非只重算分数。

### 4.3 统计预测/重复测量/条件情景题

```text
预测对象与部署单位
→ 若本问不是预测任务，先声明比较基准、分析单位与观察性边界
→ 数据层级与分组单位
→ 折内泄漏安全预处理
→ 透明朴素基线
→ 预声明候选模型
→ 与部署单位匹配的验证
→ 总体误差收益
→ 逐组失败与偏差方向
→ 目标预测与模型分歧
→ 目标域检查
→ 区间构造与覆盖语义
→ 条件输入来源
→ 采用门/停止规则
→ 外推与因果边界
```

先区分记录行数、独立对象数、配对/群组数和验证组数；若小问目标是同对象前后比较、差异描述或关联筛选而非预测部署，应先明确比较基准、分析单位和观察性边界，不因通用“基线”要求机械补入预测基线；局部特征缺失只缩小受影响指标分母，同一原始数据不能跨问相加制造更大样本。随机行级交叉验证不能证明新个体/新设备/新站点外推；填补、标准化、特征选择和拟合留在折内。总体指标之后必须检查按对象、组别、时期或尾部事件的失败结构，至少说明最差对象/时段、偏差方向或残差集中区；对时间预测，残差时序、分时期指标或尾部事件表至少保留一种。预测区间若未建立就明确写“未建立”，训练残差分位数或安全量不能直接写成未来覆盖保证。必须把模型相对基线的收益与目标对象预测是否改变分开报告。条件情景要披露输入来源、样本量、变换规则和是否重拟合，不能写成干预效果或训练保证；若题目要求建议、训练、调控、方案或理想状态，正文还要明确：决策变量、参考线/目标构造、情景旋钮、输出由哪个既定模型产生，以及满足什么采纳条件、停止/回退条件；情景旋钮只改变已声明输入时，不得把它包装成因果效应。

### 4.4 概率分类/评分与聚类/分组题

```text
概率分类/评分：
标签定义与数据来源
→ 部署对象和错误代价
→ 透明基线
→ 结构匹配验证
→ 区分能力
→ 概率校准
→ 错误类型/分组失败
→ 阈值来源与敏感性
→ 决策后果
→ 外推与因果边界

聚类/分组：
分组对象与现实用途
→ 距离/相似度及尺度
→ 簇数或容量来源
→ 组内紧凑与组间分离
→ 多初始化/参数扰动稳定性
→ 单例与异常对象
→ 分组如何进入后续决策
→ 不可解释为真实路径/自然类别的边界
```

概率输出必须把职责拆开：AUC/准确率等区分指标不等于概率校准，概率校准也不自动给出运营阈值。若阈值进入价格、分配、筛查或风险决策，要写明阈值来源、错误代价、分组校准/失败、阈值扰动及决策后果；没有混淆矩阵、成本曲线或校准证据就明确写“未建立”，不能把运营目标写成统计置信水平。聚类/分组要先说明现实用途，再报告距离或相似度、尺度、簇数/容量来源和组规模结构；只有在有相应证据时才能写组内紧凑、组间分离、多初始化一致性或参数稳定。簇数、满容量比例和可视化分开本身不是质量结论，空间邻近组也不能直接写成真实路线、自然类别或协同保证。

### 4.5 评价/综合评分题

```text
评价目标与决策对象
→ 候选对象与资格门槛
→ 指标定义、方向、单位和时间窗
→ 指标筛选、冗余与相关
→ 变换/标准化及其得分语义
→ 权重来源与主观性
→ 透明基线/等权方案
→ 综合得分与排序
→ 临界对象与权重/指标敏感性
→ 等级或入选阈值
→ 现实决策后果
→ 重算触发条件与外推边界
```

先区分“谁有资格进入评价”与“合格对象如何评分”，再写清评价目标、决策对象、指标方向/单位/时间窗、变换和权重来源。综合得分是给定候选集、指标和规则下的相对决策量，不是概率、置信度或绝对价值；AHP 一致性通过不证明权重客观，熵权只反映当前样本离散结构，TOPSIS 距离或综合得分也不自动证明唯一最优。指标相关可能造成重复计权，应给出相关/冗余诊断，并在会改变入选、等级或资源分配时比较等权或其他透明基线，报告临界对象及已有的权重、指标或阈值敏感性；未做的敏感性必须写“未建立”。排名可以决定后续分析或决策对象，但不能自动推出利润、可预测性、因果优越性或资源优先级；候选集、时间窗、指标、资格门槛或偏好变化时必须重新完整评分。

## 5. 局部叙事与证据载体最小闭环

- **核心公式**：按需形成“计算目的→公式→符号/单位/数据层级→各项计算职责→一个局部验证见证→输出进入哪张表、图或答案→验证边界/失败动作”；见证写清期望关系、实际结果与允许范围，且不能只用同一代码再次运行。不要把定义式、恒等换算或教材公式伪装成推导与创新；单位一致、代表性代入或求解器成功均不能单独证明模型正确。
- **核心结果表**：表前交代比较目的、对象、分母、单位和阅读口径；表后第一句先指出最重要的行列、方向和直接判断，再写诊断、现实意义与边界，不逐单元格复述。
- **图表**：每张图/表先登记一句主张；正文解释可见模式及其决策意义，并写不能支持的更强结论。一张图支持不了多个互不相关的主张时拆分；没有主张的图不进入正文。
- **图形编码**：先判断对象是原始观测、汇总量、模型输出还是条件情景，再选择点、线、柱、区间和连接关系。柱形/面积通常从零起；非零轴、断轴、双轴、缺失连接和区间定义必须披露。有限离散节点如需连接，只用弱化辅助线并注明“不表示节点之间的完整响应函数”；颜色至少再绑定线型、marker、轮廓、直接标签或分面。
- **图内术语与面板**：正文、图内标题/轴/图例和图注使用同一对象术语；中文主语言不要求翻译单位、变量、专名或通用缩写。不同证据职责用稳定 `(a)(b)…` 或独立图号，并按身份回指；无法核实的源图字符保留时写清“不作为何种证据”，不猜编号、分数或事件含义。
- **最终尺寸与局部可读性**：先确定最终嵌入宽度和允许图高再设置画布；源字号、源画布与 DPI/PPI 不等于最终可读。缩放估算只筛查风险，不设脱离载体的固定 pt 门；拥挤时按“删非材料性系列→缩短且登记术语→直接标签→改变方向/分面→拆图或移附录”处理，不先继续缩小字号。表达 A/B 保持数据、排序、轴域、单位、阈值、模型输出和主张不变；导出后同时检查整页、100% 或实际阅读比例局部、图注/正文邻接和下游分页。
- **选择—诊断对象交接**：若上游面板完成候选选择、下游面板只诊断入选对象，上游用非颜色标记显式给出入选状态，下游标题或直接标签重复入选对象身份；对象来自冻结结果，图内、图注和正文同名，不得只靠颜色、面板邻接或读者记忆。表达 A/B 保持数据、排序、轴域、单位、选择结果和主张不变；身份闭合不证明模型选择正确。
- **相邻载体**：先分配职责再删重复——公式定义关系，表给精确比较，图显结构/异常，图注保证独立识别，正文完成判断与边界；不能让多个载体复述同一句话，也不能以“去重”删除关键证据。
- **证据载体地址**：材料性表、图、式、附录/代码入口使用稳定、连续、可搜索编号；首次引用写清用途，结果段按编号回指，不用“下表/上图/本表”承担唯一定位。前置符号表或数据审计表可不编号，但要明确角色；不得让正文从表 3 起跳，也不得出现“图 1：图 1……”。跨页后仍可恢复编号与引用，跨页表须重复表头。
- **段落逻辑**：按“主张→证据→证据关系→判断/边界”组织；明确不同证据是并列、互补还是层层推出，连接词不得强于实际证据。
- **结果与主张登记**：结果段按“数值→比较/诊断→现实解释→边界”写；采用 `claim → evidence_refs → boundary → verification_status` 记录核心主张，状态区分 `automated`、`agent_review`、`unverified`。

### 5.1 算法执行与代码映射

算法执行：输入/状态______；初始化______；材料性循环或分支______；停止或选择______；源码/输出______；求解状态与不能推出的结论______。有限确定性枚举不写成收敛或全局最优；只有真实存在随机性时才登记种子、多次运行与稳定性。

## 6. 全文信息角色与交付收口

### 6.1 摘要—正文—结论

```text
摘要：任务对象 + 一个关键方法/结构 + 1—2 个代表性结果 + 最重要边界
逐问正文：完整定义/推导 + 候选比较 + 图表证据 + 验证、失败结构与直接回答
结论：冻结精确答案 + 可信依据 + 局限/回退条件
```

三处可以有不同压缩率，但对象、方向、单位、样本分母、验证对象和边界必须一致。摘要不得靠删除非因果、域外、非实测或回退条件换取简洁；结论不能成为第二份过程摘要。


### 6.2 结论的证据等级与行动权限

结论逐问按下列最短链回收，不用“结果合理、模型可靠、通过检验”统摄不同证据：

```text
冻结答案 → 证据等级/验证范围 → 允许动词 → 允许行动 → 禁止升级/人工闸门
```

- 直接计算：写“在本定义下计算为”，不写人工真值或额外精度；
- 观察/关联：写“观察到、相关、可作为复测线索”，不写因果或训练有效；
- 内部条件预测：写“在当前模型和匹配验证下预测”，不写实测值、任意新对象保证或总体泛化；
- 情景规划：写“预设情景下的规划参考”，不写训练反应、可达上限或承诺值；
- 带护栏建议：写清复测、拒绝、停止和责任人人工拍板，不把候选方案写成正式决策。

硬边界：结论能被复算不等于行动已经被验证；模型内部最优不等于现实最优；安全规则被写出不等于安全性已得到验证；条件推荐不等于正式决策。只有至少三种材料性结论等级需要跨问核对且能压缩信息时才制表，否则用短句。
### 6.3 数值显示精度与决策值

```text
数值显示精度：对象______；未舍入冻结值______；
测量/采样分辨率______；验证误差/不确定性尺度______；
决策用途/阈值间隔______；正文显示规则______；
舍入临界保护______；改变后重算______。
```

硬规则：机器精度不等于测量精度；模型选择、排序、阈值、可行性和停止/拒绝判断使用未舍入冻结值。若舍入可能造成并列、反转或跨阈值，保留保护位或报告临界状态；输入小数位和跨位置格式一致本身不构成精度证据。
### 6.4 正文—附录—参考文献

- 正文先写题目对象、模型关系、结果、验证和决策，内部路径、哈希、流水线状态和全量诊断下沉到附录或支撑材料；不得因“语言自然”删除复现所需的技术事实。
- 正文必须独立完成“直接回答+核心定义或推导+关键结果+验证+边界”；附录按当届规则提供可检索的证据导航、完整源码和必要明细，不能替正文补论证。
- 冻结前检查源码本地依赖闭包，并核对论文附录源码、最终正式源码与支撑包同名源码一致。
- 正文编号与文后条目双向闭合；文后条目使用已核验且足以唯一识别、复核定位的元数据。不得补造 DOI、网址、期号、页码或访问日期，也不得在未核验标准全文时宣称完全符合某一著录规范。

### 6.5 最终顺序

```text
冻结结果与主张状态
→ 回放摘要/正文/结论及公式/表/图数字
→ 完成参考文献与附录证据导航/源码同步；作者指导只留在 `% AUTHORING-GUIDANCE:` 源码注释中，逐项替换所有 `MMFINALIZE-*` 受控标记，并清除模板自带的参考文献、导航、源码及其他教学示例
→ 从唯一权威论文源重建 DOCX/PDF
→ 全页视觉、匿名、AI、规则与最终包检查
```

任一冻结结果、图表、源码、引用或分页发生变化，都要从受影响环节重新回放，不能沿用旧版视觉审计或打包结论。


**表达修复后的血缘闭环（已由阶段 136 案例验证）**：若候选稿已经完成表达提升，但导出后只发现符号表、公式或版式渲染问题，先保存修复前权威源快照，再用差异证据确认变更仅限表达层，重新绑定当前源/DOCX/PDF 哈希并重做受影响的 PDF、视觉和交付检查。候选稿哈希与当前源哈希不同本身不证明模型、数据或结果改变；但旧 PDF 哈希、旧视觉记录或旧交付 manifest 不能沿用。若差异涉及数据、代码、结果登记、验证口径、图表数据或模型参数，则不是表达修复，必须按结果冻结规则解冻、重算并重新冻结。
