# Environment And Recovery

Use the interpreter selected by the user or project. Verify its executable and installed versions; never reuse a private machine's readiness statement. Dependencies and external tools are not bundled. From the repository root, run `python -B .agents/skills/math-modeling/scripts/check_skill.py --workspace-root . --skip-historical --json` with the selected environment. Record unavailable packages and skipped tests. Do not install or change an environment without task authorization.

## DOCX-To-PDF Dual-Backend Recovery Card

The private Word exporter and downloaded LaTeX asset are not included. Do not promise document production until a separately reviewed export backend is configured. Probe Word or LibreOffice in an isolated output directory; bound the initial diagnosis to 10 minutes, then report the failure and choose an available, verified alternative. Preserve the last good output. Any new PDF requires visual inspection of every page, not merely a contact sheet or successful process exit. Never mark a missing backend or unreviewed page as passed.

## OCR And Offline Recovery

No OCR binary, trained model, installer, benchmark or recovery cache is included. Record versions, hashes and explicit paths for user-supplied tools. Validate body retrieval separately from formula transcription on a new sample. Old private benchmark numbers do not establish public-edition accuracy. Environment discovery is not an active startup test; a snapshot is not an offline rebuild proof.
