# 单变量曲线分析模型卡

## 模型名称与路由信号

单变量曲线分析用于比较一个数值自变量与一个连续响应之间的预定义曲线关系，并在观测范围内给出留出预测、残差和条件不确定性证据。它不能识别因果关系，不支持任意公式搜索，也不能把插值域内验证外推为观测范围外有效。

## 适用结构

- 每行包含一个数值 `x` 和一个连续数值 `y`，独立观测单位能够说明；
- 目标是比较线性、低阶多项式或形状保持插值，而不是处理多特征预测；
- 样本足以保留独立测试集，并在开发集完成 K 折比较；
- 测试点位于开发集观测范围内，结论限定为插值域；
- 重复测量、组结构、时间依赖或测量误差若存在，必须进入显式数据结构或测量模型，不能静默平均。

## 符号与单位

- `x_i`：第 `i` 个自变量观测，保留原单位；
- `y_i`：对应响应，保留原单位；
- `f(x)`：候选曲线的均值响应，单位与 `y` 相同；
- `e_i=y_i-f(x_i)`：交叉验证残差，单位与 `y` 相同；
- `beta_j`：多项式在原始 `x` 尺度上的系数，单位为 `[y]/[x]^j`；
- `alpha`：区间尾部概率，无量纲。

## 假设与定义风险

开发集与独立测试集代表同一观测机制；固定 `x` 条件下的交叉验证残差在拟合范围内近似可交换；预定义候选族包含足以回答问题的关系形式。独立观测单位、候选族、切分语义、允许的插值范围和响应定义若会改变结论，必须登记到模型定义寄存器。曲线关系不自动具有因果、物理或机制解释。

## 透明基线

必须包含线性曲线。它提供最低复杂度、可解释的比较起点，并阻止高阶多项式或插值器仅凭训练拟合更灵活就被采用。

## 模型构造

生产基线只比较 `linear`、`quadratic`、`cubic` 和 `pchip`。两个观测端点保留在开发集，其他点按固定种子抽取内部测试集；候选只在开发集进行 K 折交叉验证。先找到最低平均 fold RMSE，再用一标准误差规则选择阈值内复杂度最低的候选。选中模型在完整开发集重拟合，测试集只用于最终验收。

区间使用固定 `x`、交叉验证残差 Bootstrap：从中心化残差重采样并重拟合模型。均值响应区间来自 Bootstrap 拟合曲线分位数；单次观测预测区间另叠加残差抽样。多项式同时输出原始 `x` 尺度系数及 Bootstrap 区间；PCHIP 没有可比较的有限维参数区间，不能伪造。

## 输入和参数

必须提供 CSV、`x`/`y` 列、两者单位和来源说明。候选列表必须唯一且包含 `linear`；置信水平必须在 `(0,1)`，Bootstrap 次数为 200 至 10000。测试比例、折数、种子和网格点数必须记录。重复 `x` 被拒绝；若它们来自重复测量，应先声明测量误差、组内相关或合理聚合模型。

## 验证设计

- **must**：检查非数值、缺失、非有限值、重复 `x`、单位和独立观测语义；
- **must**：模型选择完全限制在开发集，独立测试集只评估一次；
- **must**：报告候选交叉验证误差、一标准误差阈值、选中模型及相对线性基线的测试表现；
- **must**：检查交叉验证残差，并报告测试预测、均值响应区间和单次观测预测区间；
- **must**：曲线网格只覆盖开发集观测范围，任何外推主张均视为未验证；
- **should**：检查残差均值、尺度变化和残差与拟合值或 `x` 的关系；
- **should**：在多项式被选中时审查原尺度系数及其区间；
- **optional**：在独立样本更充足时比较预先登记的其他曲线族或外部验证集。

## 敏感性与稳健性

比较合理的候选集合、测试比例、折数和种子；检查结论是否依赖少数端点或高杠杆观测。Bootstrap 区间只在残差交换性近似合理时使用。若异方差、组内相关、重复测量或测量误差明显，应改用与数据结构匹配的统计模型和区间方法。

## 失败模式

- 用最终测试集挑选次数、阶数、候选或区间设置；
- 用训练拟合优度替代独立测试表现；
- 把 PCHIP 插值曲线当作可解释参数模型；
- 在观测范围外画线并宣称预测有效；
- 静默平均重复 `x`，掩盖测量误差或组内结构；
- 把条件残差 Bootstrap 区间描述成包含测量、结构、定义或模型选择不确定性；
- 用单个受控案例证明现实数据中的普遍正确性。

## 替代模型与选择证据

多特征连续预测使用回归预测模型卡；时间依赖使用时间序列模型卡；连续响应的 OLS 条件关联、HC3/cluster 推断、效应量和影响点审阅使用 OLS 统计诊断模型卡。重复测量、混合效应、GEE 和稳健回归仍须按题型扩展。具有明确机理时优先参数化机理模型；需要观测范围外预测时，必须另立外推假设和独立外部证据。切换模型要基于数据结构、残差和无泄漏验证，而不是曲线视觉更平滑。

## 输出证据

`curve_analysis.py` 生成输入哈希、运行环境、列和单位、切分与候选、候选指标、交叉验证残差、曲线与两类区间、独立测试预测、可用的多项式参数区间、诊断图、警告和 `run.json`。所有论文数字应能对账到这些输出。

## 下一步动作

先完成数据审计和独立观测单位确认，再运行 `scripts/model_baselines/curve_analysis.py`。本曲线基线只依赖 NumPy、Pandas、SciPy 和 Matplotlib；`statsmodels==0.14.6` 已为独立的 OLS 统计诊断工作流锁定。重复测量、混合效应、GEE 和稳健回归若由题型触发，仍需独立契约与验证。
